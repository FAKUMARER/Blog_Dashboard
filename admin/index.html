设置

令牌只保存在本机浏览器 localStorage，不会上传到任何第三方。

外观

一键安装「博客园风格」主题（复刻 Cnblogs-Theme-SimpleMemory 的视觉，纯静态、不依赖它的 JS）。 会提交 themes/cnblog/ 并把站点主题切换过去；评论在下面「评论（giscus）」里单独配置。

首页格言

控制 banner 上那句诗。三种来源：内置诗句库、一言 API、仓库里的 motto.txt。 设置写在 themes/cnblog/_config.yml，motto.txt 写在 source/motto.txt。

评论（giscus）

评论存在仓库的 GitHub Discussions 里，不需要服务器，也没有广告和追踪。 前提：仓库是公开的、已开启 Discussions，并装了 giscus App。 去 giscus.app 选好仓库和分类， 它会生成 repoId / categoryId，填到下面即可。 设置写在站点 _config.yml，重装主题不会丢。

浏览量（GoatCounter）

每篇文章的阅读数用 GoatCounter 统计：无 Cookie、免费（非商业用途）。 先去 goatcounter.com 注册并建站点，站点代码就是 xxx.goatcounter.com 里的 xxx； 再在站点 Settings 里打开 Allow adding visitor counts on your website，否则页面上取不到数字。 设置写在站点 _config.yml，重装主题不会丢。

批量改分类

把某个分类下的所有文章整体挪到新的分类路径下。只改 front-matter 的 categories， 文件位置、日期、正文和其他字段都不动（URL 不变）。

站点初始化

在仓库里生成 Hexo 骨架：package.json、_config.yml、 部署 workflow 和一篇示例文章。已有的文章和图片不会被改动。

定时发布

把「发布日期」设为未来时间即可安排定时发布，但需要仓库里有一个定时构建的 workflow，否则文章不会自动上线。下面这个按钮会提交 .github/workflows/scheduled-rebuild.yml（按所选框架生成）。

注意：修改 .github/workflows/ 需要 token 额外具备 Workflows: Read and write 权限（classic token 则是 workflow scope）， 仅有 Contents 权限会失败。
